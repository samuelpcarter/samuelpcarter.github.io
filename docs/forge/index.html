Forge: a brain dump that files itself.

I built Forge in October 2026 to run school, two jobs and life admin from one place. I talk, it catches every item, files it and shows me where each one landed.

The problem

  • Tasks lived in a dozen places: two email accounts, texts, Canvas, group chats and calendars.
  • Things slipped through. I wanted one place that catches everything and one assistant that can act on it.

What it does

Talk, don't click

I speak into the Forge chat box. Claude splits the dump into items and files each one: done, a task or a rule.

See where it landed

A living brain lights up as each item lands, plus one view of tonight, tomorrow, this week and later.

Interrupt anytime

Messages reach the agent mid-task, so I can redirect it without waiting.

Daily agent

Every morning it checks email, texts, class sites and calendars and turns anything that needs me into a dated task.

Work hours, drafted

A script rebuilds billable hours from activity across two accounts, so timesheets aren't rebuilt from memory.

Every save versioned

Each save is committed to a private repo, and any past version can be pulled back with one click.

How it's built

  • Markdown as the source of truth. An Obsidian vault holds tasks, calendar and one handoff note per area of life.
  • A small Python server builds the dashboard, relays chat messages and runs local speech-to-text as a dictation backup.
  • Claude Code with connectors for Gmail, Calendar, Slack and the browser, and hooks that log every action to the live view.
  • Guardrails. The agent drafts but never sends, never deletes, and stops itself before a usage limit is hit.

What I learned

01

Clear written rules beat clever prompts.

02

Check work mechanically, by ID and count, not by eye.

03

The best interface is the one you glance at, not the one you click through.

Private by design

The real system holds personal data, so it runs only on my own Mac and isn't public. Happy to demo it live.
