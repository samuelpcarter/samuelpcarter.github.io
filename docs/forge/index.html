Forge

A personal AI operating system I built in October 2026 to run school, work and life admin from one chat.

THE PROBLEM

  • Two jobs, a full course load, transfer applications and volunteer roles meant tasks lived in a dozen places: two email accounts, texts, Canvas, group chats, calendars.
  • Things slipped through. I wanted one place that catches everything and one assistant that can act on it.

WHAT IT DOES

  • One chat, many jobs. I give Claude a long request and it runs several jobs side by side; a live agents board on the dashboard shows each one and pings when it finishes.
  • Scheduled agent. Three times a day it reads new email, texts and the class site, checks calendars, and turns anything that needs me into a task with a date.
  • Dashboard. One scrolling page: what's next, today in time order, the week as day cards, areas of life, goals, a Pomodoro timer.
  • Never loses a task. Anything I mention, even in passing, is written to a Kanban list before the reply.
  • Work-hours tracker. A script rebuilds billable hours from chat history and messages across two accounts, so timesheets are drafted, not reconstructed from memory.
  • Versioned. Every save is committed and pushed to a private GitHub repo, so I can see what changed and when.

HOW IT'S BUILT

  • Plain Markdown files (Obsidian vault) as the source of truth for tasks, calendar and per-area handoff notes.
  • A Python build step turns those files into the dashboard; a small Python server serves it locally and stores tickets.
  • Claude (Claude Code) with connectors for Gmail, Calendar, Slack and the browser, plus read-only access to the Mac Messages database.
  • Guardrails: the scheduled agent never sends, deletes or redesigns on its own; it drafts and files tickets for me to approve.

WHAT I LEARNED

  • Agents need clear rules more than clever prompts: a short written rulebook beat long instructions.
  • Checking work mechanically (by ID and count) catches more than "looks right".
  • The best interface is the one you glance at: short bullets and a live panel beat long replies.
